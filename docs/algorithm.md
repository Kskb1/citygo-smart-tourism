# 智能规划算法

## 输入

出发地、目的地、出发日期、游玩天数、预算、人数、兴趣偏好、交通偏好、住宿偏好。

## 数据获取

1. 高德 POI 根据目的地和兴趣关键词检索真实景点。
2. 高德天气查询目的地天气。
3. 先用高德地理编码解析出发地和目的地坐标，再用高德路线查询真实距离和耗时；解析失败时不返回假路线。
4. Amadeus 查询航班真实报价。
5. Amadeus 查询酒店真实报价。
6. 高铁默认返回 12306 官方查询跳转；配置合规第三方接口后才展示其真实结果。

## 预算

总费用由真实接口价格和规则估算组成：

- 航班或高铁费用：必须来自真实接口；否则不纳入。
- 酒店费用：必须来自真实接口；否则不纳入。
- 门票：无法从真实接口获取时提示以景区官方公告为准。
- 餐饮：规则估算，每人每天 120 元。
- 市内交通：规则估算，每人每天 30 元。

当实时酒店或航班价格未获取成功时，结果中明确提示：

“由于酒店实时价格未获取成功，本次预算估算不包含住宿费用。”

“由于航班实时价格未获取成功，本次预算估算不包含机票费用。”

当前实现会读取 Amadeus 响应中的首个航班报价 `data[0].price.total` 和首个酒店报价 `data[0].offers[0].price.total`。如果字段不存在或不是数字，则视为未获取到真实价格。
