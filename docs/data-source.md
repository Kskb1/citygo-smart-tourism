# 数据源说明

| 数据类型 | 接口提供方 | 真实数据 | 需要 API Key | 是否收费 | 失败处理 | 是否缓存 | 建议有效期 |
| --- | --- | --- | --- | --- | --- | --- | --- |
| POI / 景点 | 高德开放平台 Place API | 是 | 是 | 以高德政策为准 | 返回 `AMAP_API_KEY 未配置` 或真实错误 | 允许 | 1-7 天 |
| 天气 | 高德开放平台 Weather API | 是 | 是 | 以高德政策为准 | 不返回假天气 | 允许 | 1-3 小时 |
| 路线 | 高德开放平台 Direction API | 是 | 是 | 以高德政策为准 | 不返回假路线 | 允许 | 1-24 小时 |
| 航班报价 | Amadeus Flight Offers Search | 是 | 是 | 以 Amadeus 政策为准 | 不返回假机票价格 | 允许 | 10-30 分钟 |
| 酒店报价 | Amadeus Hotel APIs | 是 | 是 | 以 Amadeus 政策为准 | 不补酒店价格 | 允许 | 10-30 分钟 |
| 高铁 | 12306 官方跳转 / 合规第三方 API | 官方跳转不返回价格 | 第三方模式需要 | 取决于供应商 | 提示前往 12306 官方查询 | 第三方结果可缓存 | 5-15 分钟 |
| 餐饮估算 | 平台规则 | 否，规则估算 | 否 | 否 | 明确标注估算 | 可缓存规划结果 | 随规划保存 |
| 市内交通估算 | 平台规则 | 否，规则估算 | 否 | 否 | 明确标注估算 | 可缓存规划结果 | 随规划保存 |

系统禁止把 `realData=false` 的结果伪装成实时数据。
